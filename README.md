# Կգա՞ս ինձ հետ ժամադրության

Անհատական հրավերի կայք՝ ադմին պանելով։ PHP, առանց տվյալների բազայի (տվյալները պահվում են `data/store.php` ֆայլում)։

## Ինչ կա

- `/?i=<կոդ>` — հրավերի էջը. լեզվի ընտրություն (հայերեն, ռուսերեն, անգլերեն) → «Անուն, կգա՞ս ինձ հետ ժամադրության» (փախչող «Ոչ» կոճակով) → ինչ անել → օր և ժամ → տոմս։
- `/admin/` — ադմին պանել. անունով հրավերի ստեղծում, հղման պատճենում, «բացե՞լ է հղումը», քանի անգամ, պատասխանը։
- Պատասխանը գալիս է նաև մեյլով (PHP `mail()`)։

## Տեղադրում hayhost cPanel-ում

1. **Դոմեյնը.** cPanel → *Domains* → ավելացրու դոմեյնը (կամ օգտագործիր հիմնականը, որի թղթապանակը `public_html` է)։ Դոմեյնի NS սերվերները պետք է լինեն hayhost-ի տվածները։
2. **Ֆայլերը.** GitHub-ում *Code → Download ZIP*, ապա cPanel → *File Manager* → դոմեյնի թղթապանակ → *Upload* → *Extract*։ Ֆայլերը (`index.php`, `api.php`, `admin/`, `assets/`, `data/` …) պետք է լինեն հենց դոմեյնի թղթապանակում, ոչ թե ենթաթղթապանակում։
   Այլ տարբերակ՝ cPanel → *Git Version Control* → *Create* → Clone URL՝ այս ռեպոյի հասցեն, Repository Path՝ դոմեյնի (դատարկ) թղթապանակը։ Թարմացնելու համար՝ *Manage → Pull*։
3. **PHP.** cPanel → *Select PHP Version* → 7.4 կամ ավելի նոր։
4. **SSL.** cPanel → *SSL/TLS Status* → *Run AutoSSL*, որ կայքը բացվի `https://`-ով։
5. **Առաջին մուտք.** Բացիր `https://քո-դոմեյնը/admin/`, դիր գաղտնաբառը և մեյլը, որին պետք է գան պատասխանները։ Սա արա անմիջապես տեղադրելուց հետո։
6. **Մեյլի ստուգում.** Ադմին պանել → *Կարգավորումներ* → *Ուղարկել փորձնական նամակ*։ Նամակները գնում են `noreply@քո-դոմեյնը` հասցեից. եթե չեն գալիս, ստուգիր Spam-ը և ստեղծիր այդ հասցեն cPanel → *Email Accounts*-ում։

`data` թղթապանակը պետք է գրելի լինի (755)։ Թարմացնելիս `data/store.php`-ն չջնջես՝ այնտեղ են հրավերներն ու պատասխանները։

## Նշումներ

- Երբ ադմին պանելում մուտք գործած ես և սեղմում ես «Դիտել», բացումը չի հաշվվում։
- Մեսենջերների հղման նախադիտումը նույնպես չի հաշվվում որպես բացում։
- Մեկ հրավերին կարելի է պատասխանել մեկ անգամ. նորից բացելիս երևում է տոմսը։
